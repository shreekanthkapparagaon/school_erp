# Build a Production-Ready Attendance Module for School ERP

I am building a modular School ERP using **Django**, **Django REST Framework**, **MySQL/MariaDB**, and **Django Templates** (no React or Vue).

The project already contains apps such as:

* Authentication
* Schools
* Students
* Teachers
* Subjects
* Academic Years
* Classes
* Sections
* Plans & Subscriptions
* Permissions

Create a new Django app named **attendance**.

The attendance app must integrate with the existing ERP and must **never duplicate existing models**. It should use ForeignKeys to existing School, User, Student, Teacher, Subject, AcademicYear, Class, and Section models.

---

# Device Activation

The ERP must generate a temporary Device Activation Key.

The activation key:

* belongs to one school
* expires automatically
* can only be used once
* is generated by Manager

Desktop setup software sends:

Activation Key

Serial Number

Firmware Version

Server verifies:

Subscription

School

Device Limit

Activation Key

If valid:

Create Device

Generate:

Device ID

Device Secret

Invalidate the activation key immediately after successful activation.

Never store the activation key on the device.

# Coding Standards

* Follow Django best practices.
* Keep views thin.
* Use services for business logic.
* Use DRF serializers.
* Use transactions where required.
* Add docstrings.
* Follow PEP 8.
* Write reusable, modular code.
* Prepare the architecture for future RFID devices, biometric devices, mobile applications, and desktop configuration software without requiring major database changes.

Generate clean, maintainable, production-quality code with a scalable architecture suitable for deployment as a SaaS School ERP serving thousands of schools.
